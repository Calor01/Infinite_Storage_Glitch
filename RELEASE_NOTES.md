# ISG Desktop 1.0.0 — Primera versión estable

- Las barras de desplazamiento verticales se muestran únicamente si el contenido no cabe en la ventana o en la lista.
- Al agrandar la ventana o vaciar la lista, se ocultan automáticamente.
- Se mantienen las cuatro pestañas, el icono, la interfaz sin textos superfluos, el motor y los formatos compatibles.
- No se modifica el comportamiento de privacidad ni se añade historial.

**Pendiente para Tails:** auditoría de tráfico y persistencia en el sistema operativo de destino.
